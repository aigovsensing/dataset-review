            ⬇️ CSV
            ⬇️ JSON
            
          

        

        
검토 완료된 데이터셋의 종합의견(라이선스 · 데이터 생성/수집 방식 · 개인정보 포함 여부)과
          이용자가 GitHub 이슈에서 선택한 AI 자동리뷰 결과 만족도(High · Medium · Low · Bad)를
          집계·시각화한 현황입니다. 각 항목의 확인 결과 · 내부 판단 · 판단 근거를 데이터셋별로 열람할 수 있습니다.
          만족도 레이블을 선택·변경하면 자동 반영되며, 누락 방지를 위해 매일 정기 갱신도 실행됩니다.

이용 방법

        
    
          
  1. 검토 요청 탭에서 데이터셋 명칭과 관련 URL을 입력합니다.
    2. 
          
  2. 검토 요청 버튼을 누르면 GitHub 이슈 작성 페이지가 자동으로 채워진 채 열립니다.
    3. 
          
  3. 내용을 확인하고 Submit new issue를 누르면 이슈가 생성됩니다.
    4. 
          
  4. GitHub Actions가 이슈를 감지하여
            Gemini(Google AI Studio) +
            Google 검색으로
            법적 리스크를 검토합니다.
    5. 
          
  5. 검토 결과가 해당 이슈에 댓글로 자동 등록됩니다. 검토 결과 탭에서 목록을 확인할 수 있습니다.
    6. 
        

        

          ♻️ 이미 검토된 데이터셋이라면(동일 명칭의 이슈가 이미 있으면) 중복 검토를 막기 위해
          새 이슈를 만들지 않고, 기존 이슈 주소를 안내합니다. 다시 검토하려면 해당 이슈로 이동해
          rerun-review 라벨을 추가(체크)하면 재검토가 자동으로 실행됩니다.
        

        

          ⚠️ 본 검토 결과는 회사 내부 사전 리스크 검토용 참고 자료이며,
          법률 자문이나 법적 판단을 대체하지 않습니다. 확인되지 않은 사항은 "확인 불가"로 표기되며,
          이 경우 내부 검토 기준에 따라 잠재적 법적 리스크가 있는 것으로 판단합니다.

자동 검토 항목 (Legal Review)

        
    
          
  • Personal Information — 얼굴·음성·이름 등 식별정보(개인정보) 사용 여부
    • 
          
  • Copyright — 외부 저작물·데이터·코드의 출처·라이선스·사용 허가 명시 여부
    • 
          
  • Dataset Verification — 외부 Dataset 사용 vs 자체 생성(실험) 데이터 구분, 데이터 출처
    • 
        

        

          결과 말미에 “이 논문이 Dataset을 이용한 실험 논문인지”를 예/아니오로 결론짓고,
          각 판정에 논문 내 근거 위치(페이지/섹션)와 원문 인용을 함께 제시합니다.

📊 논문 검토 대시보드

          

            ⬇️ CSV
            ⬇️ JSON
            
          

        

        
논문 법무 검토 결과를 집계·시각화한 현황입니다.
          실험 데이터셋 사용 여부, 데이터 유형(외부 Dataset vs 자체 생성),
          개인정보 · 저작권 판정을 논문별로 열람할 수 있습니다. 누락 방지를 위해 매일 정기 갱신됩니다.

        

          
불러오는 중…

        

      

    


    
    

      

        
이용 방법 (논문 리뷰)

        
    
          
  1. 검토 요청 탭에서 논문 PDF 링크 또는 논문 웹페이지 URL 을 입력합니다.
    2. 
          
  2. 검토 요청 버튼을 누르면 GitHub 이슈 작성 페이지가 자동으로 채워진 채 열립니다.
    3. 
          
  3. 내용을 확인하고 Submit new issue를 누르면 이슈가 생성됩니다.
    4. 
          
  4. GitHub Actions 가 이슈를 감지하여
            Gemini로
            논문 원문(PDF/웹페이지)을 판독하고 개인정보 · 저작권 · 데이터셋 검증을 검토합니다.
    5. 
          
  5. 검토 결과가 해당 이슈에 댓글로 자동 등록됩니다. 검토 결과 탭에서 목록을 확인할 수 있습니다.
    6. 
        

        

          📄 논문 원문을 직접 판독하여 검토합니다. PDF 링크를 넣으면 원문 PDF 를 내려받아 판독하고,
          웹페이지 URL 은 페이지 내용을 읽어 검토합니다. 판단은 논문 내용에 근거하며 추측하지 않습니다.
        

        

          🔒 ResearchGate·ScienceDirect·IEEE Xplore 등은 로그인·봇 차단으로 페이지 URL 만으로는
          원문을 읽을 수 없습니다. 이때는 논문 PDF 파일을 직접 첨부하세요 —
          검토 요청 시 열리는 GitHub 이슈 작성 화면의 본문에 PDF 를 드래그&드롭하면 링크가 생성되며,
          그 첨부 PDF 를 우선으로 판독합니다. (URL 칸에는 논문 페이지 주소를 그대로 두어도 됩니다.)
        

        

          ⚠️ 본 검토 결과는 회사 내부 사전 리스크 검토용 참고 자료이며,
          법률 자문이나 법적 판단을 대체하지 않습니다.
